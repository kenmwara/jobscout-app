# Mockups — the Parallel-study redesign

Nothing in this folder is served. `site/` is what Cloudflare Pages publishes.

- **`redesign.html`** — the approved design, complete and interactive against a
  real slice of the feed. Landing / Browse / After-a-run / Mobile, Canada light
  and Kenya dark, all the motion. This is the spec.
- **`feed-sample.json`** — the slice it runs on, pulled from the live API.
- **`index.port-wip.html`** — an unfinished attempt to splice that design onto
  the live page's script. It does not run. Kept only as a reference for which
  live CSS blocks carry over; **do not deploy it**, and prefer authoring the new
  `site/index.html` deliberately over resuming the splice.

Design notes, measurements off the reference, and the list of things
deliberately not copied: `../docs/REDESIGN-parallel.md`.
